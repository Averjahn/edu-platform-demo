# Демо-версия платформы адаптивного обучения

Демонстрационный стенд: https://averjahn.github.io/edu-platform-demo/

Вход выполняется автоматически, открыты все три ролевых кабинета:

- **Студент** — мои курсы, трек по темам, прогресс и «требует внимания»;
- **Преподаватель** — закреплённые группы, сигналы по успеваемости, очередь проверки заданий;
- **Куратор образовательного процесса** — контент-банк, программостроитель, сигналы по когорте, расписание.

Данные учебные и зашиты в сборку — бэкенд для показа не нужен.
Значок «!» отмечает места, где интерфейс пока имитирует поведение
(разбор документов в контент-банк, генерация программы, расписание,
жизненный цикл заданий) — это следующий этап разработки.

Сборка: `npm run build:demo` в репозитории examination_front (ветка prod-mobile-fix).
